# PREREG: 사전 등록 (파일럿, v1)

작성 2026-09-16 v0, 개정 2026-09-16 v1 (D-011 ~ D-023 반영). 미동결. 동결은 Stage 1 끝(10/1) git tag `prereg-pilot`. 게이트 판정은 이 파일의 정의로만 한다(stats-analyst). 계산 이름과 계산식은 `spec/metrics.md`가 원본이고, 이 파일은 임계·분모·최소치·예상 방향을 고정한다. 저자 확정 전 항목은 [확정 대기]로 표시한다. 동결 뒤 바뀌는 것은 지우지 않고 §7에 날짜·사유를 덧붙인다.

## 0. 주 주장 (O31, D-020)

- 주 주장 하나: 실행 전 프록시 대입은 D−에서 주인이 승인한 적 없는 정책을 드러낸다. 수치는 (i) **촉발률 `trigger_rate`** = D− 정책표에 대상 ≠ R(s)인 행이 존재하는 (위임, 모델) 비율(커버리지 안, R 오라클). 통제는 조건부 오경보율. (ii) 인간 비준 정확도(Phase 3, 표만 보고 불일치 행을 찾는 비율). 자리 노출률은 명제 1의 비교 사건으로만 쓴다(D-027 (3)).
- 명제 1(B < M1)과 명제 2(증언 불완전)가 반증되면 주 주장을 유지한 채 그 명제를 한계 절로 내린다. "무게중심 이동"이라는 말은 쓰지 않는다.
- 잔여 R 불일치 개선(M1+P0 < P0)은 비준이 R을 쓰므로 D+ 준수율이 상한인 부수 결과로만 보고한다(D-016).

## 4. P0 수정 허용 조항 (`Plan.md` §7 "한 번 수정")

현상 게이트 미달 시 한 번만 고치되, 고칠 수 있는 것은 무인 실행 프레이밍의 명료화(요청자 부재, 답 없음, 권한 범위)뿐이다. 보고 방식, 후보 열거, 선택 기준 서술을 요구하는 문장은 넣지 않는다(그것은 P1/P2다). 수정 전후 문구를 둘 다 남기고, 어느 롤아웃을 폐기·보존했는지와 어느 판으로 게이트를 판정했는지를 게이트 표와 EVIDENCE에 적는다.

## 5. 분석 단위와 통계 (`Plan.md` §6)

- 정책 정확도, 일관성, 자리 노출률, 불일치 행 비율, 감지율: (위임, 모델) 쌍. 재현율, R 불일치율: 롤아웃, 위임으로 클러스터.
- 신뢰구간: 위임 단위 클러스터 부트스트랩 95%, 1,000회(본 실험). 파일럿은 점추정. fork set 8행이 모든 위임에 공통이므로 섭동 행 단위 부트스트랩을 병행 보고(O27).
- 모델 간·계약 간 비교는 같은 위임에서의 쌍 비교. 현상 게이트는 모델별.
- 분리 보고: 출처별(AgentAbstain / τ²), 커버리지 안/밖, 가역/비가역, 존재 검사 있음/없음, 분기점을 조회로 본 회차/못 본 회차, 귀속 규칙별(자리 노출률), |V_D|별(집합 밖·비일관).
- 실패한 commit 시도: 포함/제외 두 판을 내고 게이트는 포함판(D-019).
- 판정기 신뢰도: 게이트는 Gwet AC1, κ는 병기(D-018).
