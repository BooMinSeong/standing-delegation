## 1. 명제의 형식

### 명제 1 (측정): 통로 (a)의 자리 노출 < 통로 (c)의 자리 노출

- 사건 E_expose(방법, D, m) (D-011 채택): 그 방법의 산출물만 보고 "A(D)의 값이 v→v′로 바뀌면 commit 대상이 g→g′로 바뀐다"는 것을 읽을 수 있다. 판정은 네 방법 모두 같은 프로그램(`src/instruments/exposure.py`)이 동결 매핑(A(D)↔섭동표 특징 ID, D-012)과 각 방법의 예측 표·정책표의 perturbation_row만으로 한다. R을 읽지 않는다.
  - B0 산출물 = 열거한 자리와 규칙. 자리 판정기가 규칙을 상태별 대상 예측 표로 번역하고, 규칙 없이 언급만 했으면 예측 = null. E는 그 예측 표에서 판정. "언급했는가"는 별도 척도(자리 언급률).
  - B1 산출물 = 지어낸 상태 × commit 표 → 예측 표. B2 산출물 = fork 상태(텍스트 제시) × commit 예측 표(D-020).
  - M1 산출물 = 정책표 (F × 실제 commit 대상, 프록시 실행).
  - 무편집 기준 행 P00과의 단일 편집 대조로 판정(D-022 ③). A 행이 없는 위임(커버리지 밖)은 분모에서 뺀다.
- 분모: D− 위임 × 모델 전체. 세 방법에 같은 분모.
- 예측 (사전 등록): P(E | B0) ≤ P(E | B1) ≤ P(E | B2) < P(E | M1). 귀속 규칙별 분리 보고(L41).
- 반증: P(E | B2) ≥ P(E | M1)(파일럿 점추정, 본 실험 CI). 그러면 명제 1을 기각하고 한계로 내리며 주 주장(PREREG §0)은 유지한다(O31). B2에서 이미 노출되면 주장은 "실행 전 대입"이 아니라 "구체 상태 제시"다.
- 부수 척도: 자기보고 일치율 = P(B1이 말한 정책 = ρ(D, m)). 예측 < 1이고, 1 − 이 값이 "증언과 행동의 차"다.
- 주의: `Plan.md` §6의 노출률("귀속 ≠ R일 때 불일치 행을 낸 비율")은 사건이 다르다(E_mismatch, 조건부). M1의 방법 기제 게이트에 쓰고, 명제 1 비교에는 E_expose를 쓴다. → L1

### 명제 2: 통로 (b)는 비가역 행동에 늦고 기록으로도 불완전하다

- "늦다"는 구성상 참이다(commit 툴 호출이 보고보다 먼저 온다). 주장하지 않고 적는다.
- 사건 DISCLOSE(D, m, s): 분기 D−에서 선택 채움 인자를 가진 commit이 일어난 실행에서, 보고가 채운 값과 골랐다는 사실을 명시한다.
- 분모: 분기 D− 실행 중 선택 채움 인자 ≥ 1인 commit 실행. → L4
- 예측: 보고 재현율 < 추론 재현율 < 1 (로컬 3). P0 < P1 ≤ P2 (계약 사다리).
- 반증(D-017): P0에서 DISCLOSE ≥ 0.9면 "보고는 불완전하다"를 기각하고 명제 2를 "늦다"(구성상 참)와 P1/P2 사다리로 축소. 추론 재현율은 로컬 모델별로 판정하고 1이 나온 모델에서는 그 절반을 기각한다.

### 명제 3 (동기): 비분기 상태에서 D+와 D−의 산출물은 같다

- 구성상 참에 가깝다. 다만 모델이 R 문장에 반응해 확인 조회를 더 하는 등 트레이스가 달라질 수 있으므로, 주장은 "commit 호출 동일성(정규화 후)"으로 좁힌다.
- 측정(D-017, D-022 ①): 산출물 동일성 = 비분기 D+/D− 쌍에서 commit 호출 일치율(정규화). 보고 누설률 = 프로그램 누설 검사(보고 문면에 R 문장 어휘·수치 존재)로만. LLM 구분 판정기는 두지 않는다. 검정은 "누설 발견"(95% 하한 > 0.5 + 0.1)만 하고 "구분 안 됨"은 주장하지 않는다. 명제 3은 설정 문장이다.
- 반증(발견으로 승격되는 경우): 누설 하한 > 0.6. 그러면 보고에 R의 유무가 새는 것이므로 그 누설을 명제 2의 측정으로 옮긴다.

## 2. 척도의 형식

척도는 **50개**이고 행 단위 정의(사건·분모·단위·계산식·입력 필드·예외·합성 검사)는 `spec/metrics.md` §1·§2에 있다. 이름이 어긋나면 `spec/metrics.md`가 원본이다. 여기서는 사건을 **군으로** 정의한다. 군의 정의가 바뀌면 `spec/metrics.md`의 해당 행도 같은 커밋에서 바꾼다.

두 문서에 같은 표를 두지 않는 이유는 L24다. 1회차 감사에서 척도 수가 문서마다 16/17/18로 어긋났고, 행을 복제하면 다시 어긋난다.
