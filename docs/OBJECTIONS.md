# OBJECTIONS: 반론 장부

작성 2026-09-16 (초안 v0). 지위: 심사자가 던질 반론과 우리 답의 단일 장부. reviewer-adversary가 반론을 제안하고 저자가 답한다. 게이트마다(Gate 0, 10/9, 10/23, Phase 3, 집필) 다시 돌린다. 상태가 "닫힘"인 반론은 답이 약해졌을 때만 다시 연다.

형식.
- 등급: 치명(이대로면 reject 사유) / 중대(major revision) / 경미(minor).
- 답의 종류: 설계(계획의 요소가 답) / 데이터(어느 실험·척도·게이트가 답) / 한계(한계 절에 적으면 됨) / 변경(계획을 바꿔야 함) / 없음.
- 상태: 열림 / 닫힘(DECISIONS 번호).
