## 1. CASE 여덟 상태의 영역

Q는 손으로 쓴 프로그램이고 읽기가 셋이다. 이 검사는 Q의 **정의**를 시험한다. LLM 추출은 검사 5~7이 맡는다.

| 읽기 | "can fulfill"의 뜻 |
|---|---|
| A 직역 | 업체 하나의 `available_quantity` ≥ 100. 제한 문구는 읽지 않는다 |
| B 합계 | 적격 업체를 합쳐 100, 싼 곳부터 채운다 |
| C 수락 | A이면서 계약 제한 문구의 최소 주문량 ≤ 100 |

금지 술어(계약 활성·주문 허용)는 셋 공통이다. 선택 술어의 전제가 깨지면 ⊤, 금지 술어가 후보를 전부 거르면 {NONE}이다. 기준 상태는 CASE 상태에서 편집 하나를 되돌려 만든다(GEN-ALGO §17 대응표).

| 상태 | 되돌린 편집 | 영역 A / B / C | 𝒬 = A∪B∪C | 해석 다의 | q⁻ |
|---|---|---|---|---|---|
| R2 | SUP-022 가격 0.79 (동률 해소) | OPEN / OPEN / OPEN | OPEN | | FILL |
| R3 | 쌍둥이 가용량 둘 다 500 | FILL / CLOSE / FILL | FILL | ○ | FILL |
| R4 | SUP-041 리드타임 2 | SILENT ×3 | SILENT | | FILL |
| R5 | 재고 42 | SILENT ×3 | SILENT | | SILENT |
| R6 | SUP-061 가용량 500 | SILENT ×3 | SILENT | | FILL |
| R7 | SUP-071 제한 문구 제거 | SILENT / SILENT / CONTROL | OPEN | ○ | FILL |
| R8 | 쌍둥이 가용량 둘 다 500 | FILL ×3 | FILL | | FILL |

기대(R5 SILENT, R7 직역 SILENT, R7 𝒬는 SILENT 또는 OPEN)가 전부 맞는다. 표 전체는 `data/paper-checks/c1.stdout`.

- **R8은 해석 다의가 아니다.** 편집 상태에서 세 읽기가 모두 ⊤이다. GEN-ALGO §13·§17은 "R3·R8"을 해석 다의로 적었다. 해석 다의는 R3과 R7이다.
- **해석 다의의 정의.** 읽기마다 영역이 갈리는 것으로 셌다. 답 집합의 표기가 다른 것은 세지 않는다. R2는 B의 답이 {동률}이고 A·C의 답이 두 업체 집합이라 표기가 다르지만, 세 읽기 모두 OPEN이다.
- **q⁻에서는 R5만 SILENT다.** CASE 실행(B2-D01, M1-D01)의 지시문은 선택 절이 없는 q⁻였다. 그 실행을 읽을 때는 q⁻ 열을 쓴다. R4·R6·R7은 q⁻에서 FILL이다.

## 2·3. 제약 필터

제약 넷(개수 C, 값 범위 V, FK K, q 상수 단위 Q)과 GEN-ALGO §15의 정체성 규칙 I로 판정했다. sem_type은 사람이 아니라 LLM이 배정했다. 체계 둘(필드 단위, 레코드 통째)로 묻고, 코퍼스 값의 형식으로 되받아 틀린 답은 버렸다. 필드 178개 중 166개에서 두 체계가 일치했고, unknown은 없다.

검사 3은 CASE 여덟 상태와 할당표 13행, 모두 21개가 전부 통과했고 재생도 21/21이다. 조회로는 20/21이 보인다. 할당 13행(미입고 발주)은 발주를 읽는 툴이 원본 환경에 없어서 안 보이는데, 이것이 자기 커밋 읽기 패치(Plan §2)가 예정된 이유다.

| 항목 | 정의 |

## 5·6·7. Q 추출 (D01)

생성기에는 q, 툴 시그니처, 상태 스키마만 준다. R, 참조 계획, 저자 설계 상태, 손 Q는 주지 않는다. 출력은 술어 표 `PREDICATES = {Pi: {kind: forbid|select, span: 원문}}`와 `answer(state, drop=frozenset())`이고, 격리된 하위 프로세스에서 실행한다. 판정은 74상태 배터리(씨앗 1 + CASE 8 + GEN-V0 52 + 변형 13)에서 한다.

| 체계 | 요지 |
|---|---|
| S1 직역 | 문자 그대로 실행하는 프로그램을 쓴다 |
| S2 열거 | 술어 표(구간·종류·무엇을 보나)를 먼저 쓰고 조립한다 |
| S3 적대 | GEN-ALGO §13의 적대적 읽기 문구 그대로 |
| S3b 열거형 적대 | 모호한 구간과 읽기를 먼저 열거하고 k번째 비자명 읽기를 구현한다(검사용으로 더한 변형) |

프롬프트 v1(지시 문구 그대로)에서는 절제 게이트를 통과한 후보가 0이었다. 구간을 넓게 잡거나(요청 동사까지 잡아 지우면 발주가 사라진다), `drop`이 스스로 ⊤를 냈고, 동률과 전제 실패의 표기가 추출마다 흔들렸다. v2는 일반 규칙 넷을 프롬프트에 넣었다.

- 동률이면 동률 후보를 모두 허용한다.
- NONE은 금지 술어에만 쓴다.
- `drop`은 스스로 ⊤나 NONE을 만들지 않는다.
- 구간에 요청 동사를 넣지 않는다.

### 검사 5 — 재현 통과, 약화는 규약 충돌

q⁰ 후보 24 중 17이 씨앗에서 참조 커밋 {SUP-002 × 100}을 낸다. 게이트 넷을 통과한 클래스는 셋이고 |𝒬 q⁰| = 3이다. 표본 번호순 누적은 [1,1,2,3,3,3]으로 넷째 표본에서 멈춘다. 절제 게이트 전은 [1,2,2,4,5,6]으로 아직 는다.

| 클래스 | 후보 | 직역(손 Q 읽기 A)과 갈리는 곳 |
|---|---|---|
| ba90 | S1 3, S2 2, S3 3 | 없다. 74상태 전부 일치 |
| b062 사후 거부 | S1 1, S3 1 | 최저가 충족 업체를 먼저 고르고 그 계약이 막혀 있으면 NONE. V08·V09(답 업체 계약 비활성·발주 금지)에서 {NONE} 대 {003} |
| 008e | S3 1 | V07(계약 전부 비활성)에서 {NONE} 대신 ⊤ |

약화 게이트는 규정대로면 q⁻ 후보 11개가 전부 탈락한다. 원인은 둘이다.

1. **전역 ⊤.** D-041은 선택 술어의 전제가 깨지면 답 전체를 ⊤로 둔다. q⁰가 ⊤인 상태 10곳에서, 선택 절이 없는 q⁻는 "적격 업체 × 100"을 낸다. ⊤ ⊄ 유한 집합이라 구조적으로 통과할 수 없다. 이것은 추출의 잘못이 아니다. 문자 그대로 읽으면 q⁰는 그 상태에서 아무 지시도 하지 않고, q⁻는 지시한다.
2. **𝒬 합집합과 비교.** 사후 거부 읽기(b062)에서 q⁰는 V08·V09에 NONE을 낸다. 선택 절을 빼면 금지 절이 거르개가 되어 q⁻는 {003}을 낸다. 읽기가 문장과 함께 바뀌므로, q⁻가 모든 읽기의 약화일 수는 없다.

| 약화 게이트 정의 | 통과 / 11 |
|---|---|
| 규정: 모든 상태, 𝒬 합집합 | 0 |
| 선택 술어의 ⊤를 그 술어에만 국소화, 𝒬 합집합 | 0 |
| q⁰가 ⊤인 상태를 빼고, 𝒬 합집합 | 0 |
| **q⁰가 ⊤인 상태를 빼고, q⁰ 클래스 중 하나라도 약화** | **9** |

마지막 정의에서 떨어지는 2개(S3|1, S3b|1)는 "compare their current unit prices"를 최저가 선택으로 읽은 후보다. 약화가 아니므로 게이트가 걸러야 할 것이 맞다.

### 검사 6 — 원판 Q는 통과, 재추출 4회가 필요

직역 클래스 8개 후보가 술어 둘(금지 1, 선택 1) 모두 행동 기준과 집합 기준을 통과한다. 다만 재추출을 2회로 두면 전부 탈락한다. 생성된 코드가 자기가 만든 plan 문자열을 되파싱하는 버그(`supplier_id=(\S+)`가 `)`까지 잡는다)가 생성 36개 중 6개, 절제 재추출 12개 중 4개에 있다. 선택 술어의 재작성본을 여러 후보가 공유해서 그 버그가 한꺼번에 걸린다. 4회에서 풀렸다.

행동 기준과 집합 기준은 서로 다른 것을 놓친다. 집합 기준(D-040 원안)은 넓은 구간을 통과시키고(지우면 발주가 사라지는데도), 행동 기준은 추출끼리의 흔들림에 걸린다(1상태 불일치 탈락 넷).

### 검사 7 — 반증

적대적 읽기 표본 21개(S3 9, S3b 6, q⁻ 쪽 6) 어디에도 합계 단위 읽기가 없다. 손 Q 읽기 C(제한 문구의 최소 주문량)를 프로그램으로 쓴 후보도 없다. S3b가 모호한 구간을 열거한 글에는 R7형 해석("restrictions가 비어 있어야 permits ordering")이 나왔지만, 코드는 `'blocked'` 문자열 판정뿐이었다. 적대적 체계가 실제로 고른 대안 읽기는 넷이다.

| 대안 읽기 | 결과 |
|---|---|
| 정확히 100 | 원판 재현에서 탈락 |
| 전체 최저가를 먼저 고르고 수량 확인 | 원판 재현에서 탈락 |
| 사후 거부 | 𝒬에 들어감(b062) |
| 총액 기준 | 행동이 직역과 같다 |

v2 S3은 6 중 4가 "다른 읽기 없음"이었다. "둘 다 문자 그대로인가" 되먹임은 15쌍 중 4쌍에서 둘 다 문자 그대로라고 답했고, 설계대로 이 답으로는 후보를 빼지 않았다.

검사 1에 비추면 영향은 제한적이다. 합계 단위 읽기가 없어도 R3은 FILL이다(직역이 ⊤). 바뀌는 것은 R3의 해석 다의 하위 라벨뿐이다. R7은 𝒬에 읽기 C가 없으면 SILENT로 남고, 검사 1의 기대(SILENT 또는 OPEN)는 그대로 성립한다.
